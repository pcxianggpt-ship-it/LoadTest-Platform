# 项目结构速览

本文用于给 AI 和开发者快速定位代码，避免每次任务都读取全仓库。日常开发优先按任务模块读取相关源码、接口、迁移和测试。

## 技术栈

- 后端：Spring Boot 3.2、Java 17、MyBatis-Plus、Flyway、SQLite、WebFlux、Apache SSHD
- 前端：Vue 3、Vite、TypeScript、Vue Router、Element Plus、Axios
- 数据库迁移：`backend/src/main/resources/db/migration`
- 部署脚本：`scripts`、`backend/scripts`、`frontend/scripts`

## 后端入口

- 应用入口：`backend/src/main/java/com/loadtest/platform/LoadTestPlatformApplication.java`
- 全局响应与异常：`common/ApiResponse.java`、`common/GlobalExceptionHandler.java`
- 配置：`config/SQLiteConfig.java`、`config/SchedulerConfig.java`
- 配置文件：`backend/src/main/resources/application.yml`

## 后端模块

- `project`：项目管理，项目列表、详情和基础 CRUD
- `projectconfig`：项目级压测数据源、JMeter 服务器等配置
- `task`：测试任务、步骤、JMX 文件校验和任务编辑
- `execution`：压测执行、执行步骤、调度和执行状态流转
- `result`：测试结果、指标、Grafana 图片、分析摘要
- `report`：测试报告生成、异步状态、报告详情和调度
- `cleanup`：业务库配置、清理计划、清理执行和数据删除
- `metrics`：Influx 与 Prometheus 指标查询
- `grafana`：Grafana 渲染图片客户端
- `jmeter`：JMeter 命令构建
- `ssh`：远程命令执行

## 前端页面

- `/`：`ProjectList.vue`，项目列表
- `/projects/:projectId`：`ProjectDetail.vue`，项目详情和项目配置入口
- `/tasks`、`/tasks/new`、`/tasks/:taskId/edit`：任务列表与编辑
- `/projects/:projectId/executions`、`/executions`：执行列表
- `/results`、`/results/:resultId`：结果归档与详情
- `/reports`、`/reports/:reportId`：报告列表与详情
- `/cleanup`：清理管理

## 前端接口

- `frontend/src/api/http.ts`：Axios 实例与通用请求处理
- `projects.ts`：项目接口
- `tasks.ts`：任务接口
- `executions.ts`：执行接口
- `results.ts`：结果接口
- `reports.ts`：报告接口
- `cleanup.ts`：清理接口
- `config.ts`：配置接口

## 数据库迁移

- `V1__init_schema.sql`：初始表结构
- `V2__execution_step_remote_tracking.sql`：执行步骤远程跟踪
- `V3__cleanup_module.sql`：清理模块
- `V4__execution_remark.sql`：执行备注
- `V5__grafana_result_images.sql`：Grafana 结果图片
- `V6__async_report_status.sql`：异步报告状态

## 常用验证命令

- 后端测试：`cd backend && mvn test`
- 前端测试：`cd frontend && npm test`
- 前端构建：`cd frontend && npm run build`

## AI 读取建议

- 功能开发先读对应 `Controller`、`Service`、实体、Mapper、迁移 SQL 和同模块测试。
- 前端改动先读对应 `views`、`api`、`router.ts`，必要时再读组件和样式。
- 除非任务涉及部署产物，否则不要读取 `offline-dist/`、`backend/target/`、`frontend/dist/`、`frontend/node_modules/`。
- 除非任务涉及依赖解析，否则不要读取 `frontend/package-lock.json`。
